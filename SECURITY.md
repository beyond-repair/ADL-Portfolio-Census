# Security

This repository is a locked inventory checker. It does not call GitHub, does not accept credentials, and does not execute portfolio code.

## Reporting

Report issues against [ADL-Governance](https://github.com/beyond-repair/ADL-Governance). Do not open a security advisory that claims this checker validates physics, cognition, or live repository completeness.

## Scope

- Supported: structural validation of the 2026-09-04 snapshot.
- Not supported: secret storage, network clients, dependency installs beyond pytest in CI.
